# Kirat Singh’s portfolio

A personal portfolio featuring selected software projects, open-source contributions, and an interactive koi pond.

## Run locally

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

Vite writes the static site to `dist/` for deployment on Vercel or another static host.

## Site structure

- Home page with the koi pond and selected projects
- Project index with dedicated case study routes
- Open-source contribution list with upstream pull request links
- About page with GitHub and LinkedIn links

Project descriptions live in `src/data/projects.ts`. The dated evidence inventory in `research/` is internal source material and is not included in the public build.
